# RSP0006: StackExchange.Redis compatibility

The following API surface is marked with `[Experimental("RSP0006")]`:

Every public API in `Respire.StackExchangeCompat`, including its connection multiplexer and conversion extensions,
and in `Respire.Testing.StackExchangeCompat`, including its in-memory connection fixture.

The adapter's supported subset and compatibility contracts are still settling. Opting in does not expand the supported StackExchange.Redis API surface. These APIs are outside the 2.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0006`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0006</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0006` before the experimental code and `#pragma warning restore RSP0006` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [feature guide](../guides/stackexchange-interop.md) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
