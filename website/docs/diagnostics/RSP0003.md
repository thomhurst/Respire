# RSP0003: Hedged reads

The following API surface is marked with `[Experimental("RSP0003")]`:

`RespireHedgedReadOptions` and `RespireOptions.HedgedReads`.

The delay and extra-load policy for duplicate reads are still settling. Enabling hedging can send an additional read to another eligible server. These APIs are outside the 2.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0003`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0003</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0003` before the experimental code and `#pragma warning restore RSP0003` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [feature guide](../fundamentals/connections.md#hedged-reads) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
