# RSP0002: AI caching and chat history

The following API surface is marked with `[Experimental("RSP0002")]`:

Every public API in `Respire.AI`, including `RespireSemanticCacheOptions`, `UseRespireSemanticCache`, `RespireChatHistoryStore`, `UseRespireChatHistory`, and `RespireChatHistoryProvider`.

Cache eligibility, history retention, scoping, and the Microsoft.Extensions.AI and Microsoft Agent Framework integration contracts are still settling. These APIs are outside the 2.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0002`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0002</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0002` before the experimental code and `#pragma warning restore RSP0002` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [semantic cache guide](../guides/semantic-cache.md) and [chat history guide](../guides/chat-history.md) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
