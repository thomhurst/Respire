# RSP0005: Deferred raw commands

The following API surface is marked with `[Experimental("RSP0005")]`:

`Execute(RespireCommand, params RespireValue[])` on `IRespireCommandQueue`, `RespireBatch`, and `RespireTransactionBase`, including its inherited use through `RespireTransaction` and `RespireWatchedTransaction`.

Supported key layouts and queueing contracts for the deferred raw-command escape hatch are still settling. Typed batch facets and immediate raw execution retain their existing status. These APIs are outside the 1.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0005`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0005</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0005` before the experimental code and `#pragma warning restore RSP0005` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [feature guide](../guides/deferred-raw-commands.md) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
