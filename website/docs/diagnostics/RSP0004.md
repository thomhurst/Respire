# RSP0004: Hash import sessions

The following API surface is marked with `[Experimental("RSP0004")]`:

`RespireHashImportSession`, both `IRespireHashCommands.CreateImportSessionAsync` overloads, and the `IRespireBatchHashCommands` members `PrepareImport`, `Import`, `DiscardImport`, and `DiscardAllImports`.

The connection-bound fieldset and batch/transaction contracts for Redis 8.10 HIMPORT are still settling. These APIs are outside the 1.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0004`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0004</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0004` before the experimental code and `#pragma warning restore RSP0004` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [feature guide](../guides/hash-import.md) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
