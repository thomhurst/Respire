# RSP0001: VectorData integration

The following API surface is marked with `[Experimental("RSP0001")]`:

Every public API in `Respire.VectorData`, including its stores, collections, mappers, and filter helpers.

The mapping, filtering, and hybrid-search contracts are still settling alongside the VectorData integration. These APIs are outside the 2.0 compatibility promise: signatures and behavior may change or be removed in a later release, including a minor or patch release.

Using this surface produces compiler diagnostic `RSP0001`, reported as an error until explicitly suppressed. To opt in for your project, add:

```xml
<PropertyGroup>
  <NoWarn>$(NoWarn);RSP0001</NoWarn>
</PropertyGroup>
```

For a smaller scope, use `#pragma warning disable RSP0001` before the experimental code and `#pragma warning restore RSP0001` afterward. Suppress only the feature IDs you have reviewed; disabling warnings-as-errors does not opt in.

See the [feature guide](../guides/vector-data.md) for usage and limitations, and the [experimental API policy](../experimental-apis.md) for compatibility and diagnostic naming.
